# 第三轮：交互与界面文档（UX/UI 设计规范）

> **角色**：交互设计师  
> **适用范围**：《维度之外 · Beyond 3D》从零新建项目全局交互与 HUD 界面契约（第 1–18 关统一遵循）。  
> **核心目标**：让零四维基础的玩家凭借**单一核心四维输入（鼠标滚轮）**在 10 秒内上手四维操作，并确保每一次操作都有明确、诚实、即时的视听反馈。

## 一、全局统一操作方式规范（对应 D8）

| 输入设备 / 按键 | 核心功能 | 适用阶段与状态 |
|---|---|---|
| **鼠标移动** | 第一人称 360° 视角环视（第 2–4 关失重下为 6-DOF 全向环视） | 行走 / 漂浮态 |
| **鼠标左键拖拽** | 在第三人称抓取旋转舞台中，**在三维空间（`SO(3)`）连续旋转被抓取物体**；在第 10–12 关星图台中为 360° 环绕观察棋盘 | 抓取旋转舞台（第 14–18 关） / 星图台（第 10–12 关） |
| **鼠标滚轮（唯一四维控制）** | ① **行走态**：保持自身 `XYZ` 坐标不动，沿第四维 **`W` 轴平滑平移切换空间切片**；<br>② **抓取态**：绕关卡预设的二维平面（如 `YZ` 面）对物体施加**四维刚体旋转（如 `XW` 旋转）**；<br>③ **星图推箱态（第 10–12 关）**：跨 `W = 1..4` 切片移动或沿 `W` 轴推箱子 | 第二章全局（第 5–18 关） |
| **`W` `A` `S` `D`** | 前后左右移动；在抓取舞台中（如第 6、14 关）推动物体沿轨道滑行 | 全局 |
| **`Space` / `Ctrl`** | 跳跃（第 9 关天梯） / 失重升降（第 2–4 关） / 星图台上下楼层（`+Z` / `−Z`，第 10–12 关） | 全局 |
| **`Shift`** | 冲刺加速 | 行走 / 漂浮态 |
| **`E` 键** | **核心交互与抓取键**：激活录音/锁盘/拾取物品；在四维物体旁按 `E` **进入/退出第三人称抓取旋转舞台** | 全局 |
| **`Q` / `E`（长按）** | 仅在第一章第 2–4 关失重漂浮状态下用于机身左右滚转（Roll） | 第 2–4 关失重态 |
| **`Tab` 键** | **诚实视图切换键**：<br>• 第 1–4 关：光学望远镜拉近；<br>• 第 8 关：开启三层 S 形走廊叠合俯视图；<br>• 第 10–12 关：切换 `XYZ（按 W 展开）⇄ XYW（按 Z 展开）` 基底；<br>• 第 14–18 关抓取舞台：切换 **`当前切片 W=0 + 四维投影示意` ⇄ `侧面视图 (XZW/YZW)`** | 全局 |
| **`F` 键** | 一键展开 / 收起右侧**高维全息操作台**（上帝视角三切片横向展开辅助视图） | 全局 |
| **`I` 键** | 打开 / 关闭**开场四维原理类比导览**（二维硬币立起过缝 ⇄ 三维圆球绕面转入第四维实时交互动画，启迪直觉但不剧透解法步骤） | 全局 |
| **`H` 键** | **请求角色分级口头提示**（依次触发 1 级现象提醒 → 2 级思考方向 → 3 级明确解法） | 全局 |
| **`Z` 键 / `R` 键** | `Z`：单步撤销（第 10–12 关推箱子）；`R`：快速重置当前关卡状态 | 全局 |
| **`Esc` 键** | 暂停游戏、释放鼠标指针、打开 1–18 关选关面板与音量/灵敏度设置 | 全局 |

## 二、核心操作即时反馈设计

| 玩家操作 | 视觉反馈 | 听觉反馈 | 机关与几何动画 | 无效 / 受阻操作反馈 |
|---|---|---|---|---|
| **滚轮切换 `W` 切片（行走态）** | 屏幕四周边缘掠过对应层色彩微光（青 `#4DE6D3` / 金 `#F7C346` / 蓝 `#58A6FF`）；目标切片建筑从 `35%` 发光线框虚影平滑凝实为 `100%` 不透明实体；右侧竖直 `W` 标尺与高维台小人实时同步滑动。 | 轻柔的晶体玻璃共鸣滑音，音高随 `W` 值连续变化（`W = −1.8` 深沉、`W = 0.0` 清澈、`W = +1.8` 明亮）。 | 当前层地板网格微光涟漪扫过，异层墙体退为半透明线框。 | 到达 `W` 轴边界或撞上“全 `W` 封死墙”（第 7 关反例柜、第 14 关一线天巨墙）时，墙面泛起暗金涟漪并发出低沉浑厚的止位共鸣音。 |
| **按 `E` 抓取物体 + 滚轮四维旋转** | 镜头平滑过渡至第三人称抓取操作舞台；主画面同时呈现物体在 `W=0` 的三维实心截面与半透明四维投影外框；左上角实时刷新四维旋转角度 $\theta$ 与不变量指标（如截面半宽 $x_{\max}$、有向体积 $\det$、拓扑环绕数）。 | 抓取时发出清脆的磁吸锁定音；滚轮旋转时伴随连续的精密齿轮/力场谐振音。 | 球体/球壳/圣钥/瓶颈随滚轮平滑改变三维截面形态（如 2 米球在 $90^\circ$ 收窄为 $0.07\text{ m}$ 薄刃）；左侧 `XZW` 侧面全息台同步旋转刚体圆盘。 | 在第 14 关窄缝内部试图提前转回 $0^\circ$、或第 16 关手性未反转（$\det > 0$）试图插入锁孔时，接触面闪烁琥珀色阻挡光环并发出清脆的碰撞弹回声。 |
| **按 `Tab` 切换诚实双视图** | 镜头或全息画中画平滑切入 `XZW / YZW` 侧面视图或三层叠合俯视图；顶部视图角标高亮切换并明确标注当前视图的几何含义（“当前切片 W=0”、“四维投影示意”或“侧面视图 XZW”）。 | 柔和的全息投影展开音效。 | 坐标轴标尺动态翻转对齐新基底。 | — |
| **跳跃 / 跨维落脚（第 9 关）** | 脚踏实地瞬间，实心踏板表面扩散一圈同色光环涟漪。 | 清脆稳健的磁靴落点声。 | 已登上的踏板边缘灯带转为常亮白金色。 | 踩中尚未凝实的异层虚影踏板时，无死亡黑屏，触发 `0.4 秒` 柔和白闪并无痛拉回上一块安全踏板。 |
| **达成阶段三拍 / 关卡通关** | 核心机关转为纯净白金色 `#FFF6D6`，圣殿/大厅主能量光束贯通，左侧三拍进度卡（① 奇观 → ② 把玩 → ③ 运用）打勾点亮。 | 上扬的恢弘三和弦晶体共鸣音 + 角色肯定语音。 | 闸门开启、圆环桥凝实或克莱因瓶能量环流全线贯通。 | — |

## 三、UI 元素清单及极简布局规范

严格遵循 **“画面 85% 以上面积留给 3D 空间奇观本身，零打卡清单干扰”** 的布局原则：

1. **屏幕正中 — 动态智能准星**：
   - 平时为极小半透明白点；
   - 对准当前切片可交互/可抓取物体时，化为对应强调色菱形并浮现简洁提示（如 `[E] 抓取通行珠`）；
   - 对准位于其他 `W` 切片的虚影物体时，准星变为灰色虚线框并轻提示 `位于 W=+1.8 流金层（滚动滚轮切层）`。
2. **屏幕顶部居中 — 角色语音单行字幕条**：
   - 仅在林夏（07 号）或遗迹 AI「墓地」说话/给出提示时柔和浮现，显示发言者名称与单行台词，播完后自动弱化，绝不遮挡中央视野。
3. **屏幕左上角 — 空间切片角标与三拍探索卡片**：
   - **切片与视图诚实角标**：实时显示当前所在层位（如 `W = +0.0 青苍切片`）以及抓取舞台下的视图性质声明（`当前切片 W=0 · 外框为四维投影示意` 或 `侧面视图 (XZW) · 四维刚体主轴半径恒为 1.00m`）。
   - **三拍探索反馈（奇观 → 把玩 → 运用）**：不做长篇文字说教，仅在玩家亲手触发对应阶段的发现时，自然点亮该拍进度条。
4. **屏幕右上角 — 轻量化辅助工具栏**：
   - **`💡 H · 提示 (0/3)` 按钮**：默认安静不打扰；当玩家在同一阶段停滞满 **45 秒** 时，按钮边缘泛起温和的呼吸光晕，提醒玩家可按 `H` 听取林夏或「墓地」的下一级口头提示。
   - **`🎙️ 配音 开/关`**、**`F · 隐藏/显示高维操作台`**、**`Esc · 暂停/选关`**。
5. **屏幕右侧（可按 `F` 随时折叠隐藏） — 高维全息操作台 + 竖直 `W` 相位标尺**：
   - **竖直 `W` 轴三色相位标尺**：直观标出 `W = +1.8（金） / 0.0（青） / −1.8（蓝）` 及玩家当前所在的连续 `W` 游标。
   - **3D 高维展开视口**：用独立 3D 镜头将三个 `W` 切片沿水平方向拉开并排渲染，帮助玩家随时对照“第一人称原位切层”与“四维空间横向移动”的等价关系。

## 四、交互防迷茫硬性自检表

> **硬性设计准则**：玩家做出任何一次操作后，必须在 **0.2 秒内**直觉判断出 **“我刚才的操作生效了没有 / 做得对不对”** 以及 **“接下来我该往哪个方向试”**。

1. **如何让玩家立刻看懂“我做得对不对”？**
   - **几何状态数值与形态双重可视化**：
     - 在切层关卡（第 5–9 关），切对层位时虚影立刻变为高对比度不透明实体，切错层位时保持半透明线框；
     - 在四维旋转关卡（第 14–18 关），滚轮旋转时物体的三维截面宽度 $x_{\max}$、圆环半径 $r$、有向体积 $\det$、宇航服示意截面大小或克莱因瓶短路红光会**随滚轮实时连续变化**——转对方向时截面收窄/对准卡槽/短路减弱，转反方向时截面变宽或由林夏实时语音提醒“转反啦”。
2. **如何让玩家立刻知道“接下来该往哪想”？**
   - **跨维目标全程保留虚影锚点**：无论是隔着玻璃墙的黑匣子、异层的悬空阶梯，还是北侧基座与圆环卡槽，在任何切片下都保留 `30%–35%` 的发光轮廓，玩家永远看得到终点在哪里。
   - **45 秒无打扰三级提示兜底**：既保护了核心玩家独立发现四维规律的惊喜感，又确保零基础玩家在卡住 45 秒后能通过按 `H` 获得从“观察现象（1 级）”到“操作维度（2 级）”再到“明确步骤（3 级）”的阶梯式引导。
