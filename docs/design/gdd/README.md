## 三、项目负责人（创意总监）与 AI Agent 协作准则

1. **文档即契约（Doc-Driven Greenfield Build）**：所有文档之间无历史版本冲突，均以 [00-master-gdd.md](00-master-gdd.md) 的 18 关架构为准。
2. **先做垂直切片，再铺全量关卡**：AI Agent 必须先交付 **Phase 1（公共系统 + 第 14 关「发丝裂缝」3D 垂直切片）**，由负责人试玩确认滚轮旋转手感、双视图可读性与语音提示节奏后，再按 `1 → 18` 关顺序推进。
3. **几何诚实性铁律**：每一关的四维坐标、截面公式、拓扑不变量都必须有对应的 Node.js 单元测试支撑，并在画面角标上诚实区分“当前切片 `W=0`”、“四维投影示意”与“侧面视图（`XZW`/`YZW`）”。
