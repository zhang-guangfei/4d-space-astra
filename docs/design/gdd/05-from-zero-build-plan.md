# 《维度之外 · Beyond 3D》从零新建项目开发与架构指南（面向全新 AI Agent）

> **角色**：技术主程 / 架构师  
> **目标读者**：接手本文档包、**从零开始新建《维度之外 · Beyond 3D》项目仓库（Greenfield Project）**的 AI Agent 或开发团队。  
> **核心原则**：
> 1. **纯绿色新建项目**：本项目从空白仓库起步，不依赖任何历史旧项目的包袱或废弃关卡，严格按照 [00-master-gdd.md](00-master-gdd.md) 已确认的 **D1–D13 决策与 18 关规范** 构建。
> 2. **数学内核与 3D 渲染解耦**：所有四维几何计算、碰撞判定、拓扑不变量与关卡状态机必须先写成**零 DOM / 零 WebGL 依赖的纯数学模块（Pure ESM Core）**，配齐 Node.js 自动化单元测试（100% 确定性通过），再接入 Babylon.js 3D 渲染层。
> 3. **垂直切片先行（D13）**：先构建公共四维操作系统与最具代表性的**第 14 关「发丝裂缝」垂直切片**，验证手感与诚实双视图后，再按第 1 关 → 第 18 关顺序全量铺开。

### Phase 1：公共四维交互系统 + 第 14 关「发丝裂缝」3D 垂直切片（先行里程碑 · D13）

> **目的**：在铺开全部 18 关之前，先用 1 个最具代表性的全新四维旋转关卡，把**“滚轮唯一控四维 + `E` 抓取旋转舞台 + `Tab` 诚实双视图 + `H` 键 45 秒三级提示 + 墓地低音混响语音”**整套核心体验跑通并交付试玩。

- [ ] **1.1 统一输入与第三人称抓取舞台（`input-controller.js` + `grab-stage.js`，对应 D8）**：
  - 行走态：鼠标移动环视，`WASD` 行走，**鼠标滚轮 = 自身沿 `W` 轴平滑平移**。
  - 抓取态（走近四维物体按 `E`）：镜头切入第三人称抓取旋转舞台；**鼠标左键拖拽 = 三维旋转（`SO(3)`）**；**滚轮沿 W 轴移动，Shift + 滚轮 = 绕关卡预设平面发生四维旋转（如绕 `YZ` 面的 `XW` 旋转）**。
  - 诚实双视图切换（按 `Tab`）：在**`当前切片 W=0 · 外框为四维投影示意`**与**`侧面视图 (XZW) · 四维刚体主轴半径恒为 1.00m（从未被压扁）`**之间一键切换。
- [ ] **1.2 去打卡化三拍 HUD 与 45 秒三级口头提示（`tiered-hints.js`，对应 D5、D12）**：
  - 左上角仅展示“① 奇观 → ② 把玩 → ③ 运用”三拍渐进点亮反馈，开场不弹做题清单。
  - 同一阶段停滞满 **45 秒**右上角提示灯柔和呼吸提醒；按 **`H` 键**依次播放 **1 级（现象提醒）→ 2 级（思考方向）→ 3 级（明确解法）** 角色语音与单行字幕。
  - 实装双角色语音（`character-voice.js`）：林夏（`linxia`）与遗迹 AI「墓地」（`tomb`，196Hz→147Hz 双三角波金属共鸣音 + 0.84 倍降调混响）。
- [ ] **1.3 第 14 关「发丝裂缝」完整 3D 场景与几何内核（`sanctuary-4d.js` + `chapter2-sanctuary.js`）**：
  - **地标**：C 区圣殿曜石暗金风格，两座 $6.8\text{ m}$ 巨墙夹出宽仅 $0.164\text{ m}$（半宽 $0.082\text{ m}$）的白金发丝裂缝，墙体在**所有 `W` 切片**均存在。
  - **近零厚度三维球体截面公式（方案 A · 严格切片诚实性）**：本征半轴 $R = 1.0\text{ m}$（直径 $2\text{ m}$）、$W$ 极微半厚 $\varepsilon = 0.001\text{ m}$；默认主视图仅渲染纯净 `W = 0` 切片（无四维投影壳叠加），绕 `YZ` 面仅转几度时切片半厚 $a_X(\theta) = \dfrac{R\varepsilon}{\sqrt{R^2\sin^2\theta + \varepsilon^2\cos^2\theta}}$ 即刻坍缩成二维圆盘；而全 `W` 碰撞由四维总半宽决定：
    $$x_{\max}(\theta) = \sqrt{R^2\cos^2\theta + \varepsilon^2\sin^2\theta}$$
  - **三拍闭环**：① 滚轮切 `W` 发现巨墙全 `W` 封死；② 按 `E` 抓球，三维拖拽宽度不变，按住 Shift 拨滚轮刚转几度纯净 `W=0` 切片立刻坍缩为二维圆盘，转至 $\theta = 90^\circ$ 四维总宽收窄为 $0.002\text{ m}$ 薄刃（按 `Tab` 展开 `XZW` 侧面圆盘与四维包络并锁定三维拖拽轴向，证明主轴半径恒为 $1.00\text{ m}$）；③ 按 `W` 推过窄缝（采用南侧→缝心潜望→北侧三段无遮挡镜头调度，缝内禁止提前转回 $0^\circ$），抵达北侧金色基座后滚轮转回 $0^\circ$ 恢复完整两米圆球通关。
