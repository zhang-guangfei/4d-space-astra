## 二、几何与建模风格

选择 **锐利极简几何（Crisp Minimalist Architectural Geometry）**：
1. **干净的几何原语与清晰轮廓**：所有建筑地标与解谜机关均由高精度的平面、切角立方体、圆环（Torus）、球面（Sphere）、棱柱与参数化曲面（如克莱因瓶管状曲面）构成，严禁使用杂乱的写实脏旧贴图或高频噪波纹理。
2. **每关一座专属大型地标（拒绝重复方盒子）**：
   - 第 1–4 关从四段式带舷窗雕像的玻璃长廊，演变为六门全开的失重球形气闸舱、共棱金光陀螺舱，再到悬浮水银镜面球的八室星环；
   - 第 5–12 关每关拥有截然不同的空间构图（竖向叠放的千页书板 → 12 米直径相扣双环巨门 → 左右并排的双生密封玻璃柜 → 悬空盘旋的三蛇 S 形回廊 → 20 米无底星渊阶梯 → 四联屏立体全息星图台）；
   - 第 13–18 关呈现巨物崇拜式的几何奇观（刺穿天地的无限光轴与无限光膜 → 7 米高的一线天暗金双碑 → 6 米悬空纯白球壳 → 红蓝绿非对称手性圣钥巨门 → 纯白静滞光环室 → 30 米高流金水晶克莱因瓶）。
3. **第 17 关截面的科幻线框化原则（对应 D11）**：
   - 当展示物体或角色（林夏）部分弯入第四维 `W` 而在 `W = 0` 留下的三维截面时，**严禁使用任何写实人体、器官或医疗视觉元素**；
   - 统一使用**柔和青白色（`#A5FCF2`）自发光几何线框**绘制宇航服内部的能量管线、环形接口与机械骨架，并在截面旁固定附带全息角标 `示意：宇航服能量线路截面`。

## 三、光影与材质渲染规范

1. **严格的「实体 vs 异层虚影」双态材质法则**：
   - **当前 `W` 层实体（Solid State）**：不透明度 `alpha = 1.0`，开启深度缓冲写入（Depth Write ON），具有清晰的漫反射与高光反射，确保三维空间遮挡关系 100% 稳定，绝不出现半透明排序闪烁。
   - **相邻 `W` 层虚影（Ghost State）**：不透明度 `alpha = 0.30 ~ 0.35`，叠加对应层的自发光（Emissive）与细线框，关闭深度写入（Depth Write OFF）且不使用 Depth Pre-pass，确保异层虚影既清晰可见、又绝不会遮挡或擦除背后的实体建筑。
2. **三渲染组（Rendering Groups）分层管线**：
   - `Group 0`：大空间背景穹顶、地面网格与当前层静态墙体；
   - `Group 1`（保留 Group 0 深度缓冲）：解谜核心机关、可抓取四维球体/圆环/圣钥/克莱因瓶、异层半透明虚影；
   - `Group 2`（保留 Group 0/1 深度缓冲）：同伴林夏（07 号）、第三人称宇航员 08 号与全息辅助线框，确保角色与关键线框永不被半透明地板吞没。

## 四、UI 字体与排版规范

- **主界面与叙事字幕**：采用现代几何无衬线字体（`Inter` / `PingFang SC` / `Noto Sans SC` / `Microsoft YaHei`），字重清晰，行距舒展。
- **四维坐标与几何参数读数**：统一采用等宽数字字体（`JetBrains Mono` / `ui-monospace` + `tabular-nums`），用于显示 `(X, Y, Z, W)` 坐标、旋转角 $\theta = 90^\circ$、截面半宽 $x_{\max} = 0.035\text{ m}$、有向体积 $\det = -1.68$ 与拓扑环绕数 `Linking = 1`，传递精密科学仪器的质感。

## 五、防视觉噪音硬性区分表

| 视觉元素类别 | 色彩约束 | 形态与发光约束 |
|---|---|---|
| **可交互机关 / 可抓取四维物体 / 跨层通路** | **必须且只能**使用三大层位强调色（青 `#4DE6D3`、金 `#F7C346`、蓝 `#58A6FF`）或完成态白金/翠绿。 | 具有柔和自发光（Emissive）、清晰的几何边缘线框或缓慢的呼吸/旋转动态；靠近或准星对准时有明确高光反馈。 |
| **不可交互背景建筑 / 封死墙体 / 装饰立柱** | **严禁使用高饱和青/金/蓝强调色**；只能使用各分区的低饱和度主色与辅助色（雾白、冷灰、曜石暗褐，饱和度 $\le 18\%$）。 | 大面积平整哑光表面、静态结构线，无动态闪烁，确保自动退居视觉背景。 |

## 六、这套视觉规范如何服务于四维解谜可读性

在四维空间游戏中，玩家的大脑需要同时处理“三维空间透视 $(X,Y,Z)$”与“第四维切片/旋转 $(W, \theta)$”两重信息。本规范通过**“背景极简降噪 + 强调色严格绑定 W 层位与可交互性 + 实体/虚影双态深度分离 + 诚实双视图角标”**四大手段，把整个 3D 画面变成了一张直觉可读的空间拓扑图：玩家迈入任何一关，低饱和度的空间站/巨厅/圣殿背景自然衬托出空间尺度，而高饱和度的青、金、蓝发光几何体立刻跳入眼帘——玩家无需阅读说明文字，仅凭颜色和虚实就能在一秒内看懂“什么能抓、什么在哪一层、转了滚轮之后截面发生了什么变化”，把 100% 的专注力留给四维几何的奇观与顿悟。
